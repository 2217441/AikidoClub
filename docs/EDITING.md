# Editing the Website

For committee members. No coding required.

## Where to go

**<https://2217441.github.io/AikidoClub/admin/>**

Sign in when prompted. If you can't get in, you need to be added to the
repository first — ask whoever maintains the site (see [CMS-SETUP.md](CMS-SETUP.md)).

## What you can edit

| Section | Use it for |
| :--- | :--- |
| **News** | Announcements — registration open, upcoming events, results |
| **Activities** | Ongoing or upcoming activities shown on the home page |
| **Past Activities** | The archive of events that have happened |
| **Mainboard** | Each tenure's committee chart |
| **FAQ** | Questions newcomers ask |
| **Testimonials** | Quotes from members |

## How to post

1. Pick a section on the left
2. Click **New ...** (or an existing entry to change it)
3. Fill the fields — anything not marked optional is required
4. Click **Save**

Your change is published automatically in **2–3 minutes**. Refresh the live
site to confirm it worked.

## Things worth knowing

**Saving publishes immediately.** There is no draft or review step. What you
save goes on the public site.

**Fill every required field.** If a required field is left empty the site
fails to rebuild and your change won't appear. Nothing breaks permanently —
but nothing publishes either, and you won't get an error message on screen.
If your change hasn't shown up after five minutes, that's usually why.

**News posts expire on purpose.** Old announcements stop showing
automatically so the site never looks abandoned. Don't delete last semester's
post — it will retire itself.

**Images** upload straight in the editor. Use a reasonably sized photo; a
20 MB camera file makes the site slow to load on mobile data, which is how
most students will see it.

**Mainboard needs a `tenure`** in the form `24/25`. That's what groups and
labels the charts.

## If something looks wrong

Nothing you do in the CMS is unrecoverable — every change is a saved version
in the repository and can be restored. Say what you changed and roughly when;
that's enough to find and undo it.
